# 용인 출장마사지 사이트

경기도 용인시 전지역 방문 관리 서비스(출장마사지·홈타이) 안내 정적 사이트입니다.

**상호**: 88마사지  
**예약전화**: 0508-202-4719

## 구조

- **정적 HTML 사이트** — 어느 호스팅(GitHub Pages, Netlify, 웹서버)에서든 그대로 서빙 가능
- **build.py** + **content/** — 페이지를 Python으로 정의하고 정적 HTML 생성
- **생성물** — 각 디렉터리의 `index.html`, `sitemap.xml`, `robots.txt`

```
build.py                    # 빌드 스크립트
content/
  site.py                  # 상호·전화·도메인·메뉴
  main.py                  # 메인 페이지
  areas.py                 # 지역별 페이지 (30개)
  stations.py              # 역세권 페이지 (24개)
  areas_and_stations.py    # 생활권 페이지 (16개)
  info.py                  # 정보 페이지 (예약·가이드·약관)
assets/
  style.css                # 럭셔리 다크 + 오렌지 + Pretendard
  nav.js                   # 모바일 네비게이션
gyeonggi/yongin/
  index.html               # 생성된 메인 페이지
```

## 빌드

```bash
python3 build.py
```

빌드 시 페이지별 본문 글자수 리포트가 출력됩니다.

## SEO 운영 원칙

- 본문 **2,000자 미만 페이지는 자동 `noindex`** 처리
- **구별 페이지**: 처인구, 기흥구, 수지구 (3개)
- **지역별 페이지**: 처인구 12개 + 기흥구 12개 + 수지구 6개 (총 30개)
- **역세권 페이지**: 용인 3호선·분당선 24개역
- **생활권 페이지**: 16개 (구 + 주요 역세권 조합)
- **상단·하단 메뉴**: 키워드·지역명 대량 나열 없음 (지역명만 표시)
- **모든 페이지**: 고유 작성 (지역명만 바꾼 복붕 없음)
- **Google SEO**: E-E-A-T, 도움되는 콘텐츠, Who/How/Why 원칙 준수

## 개발 현황

### 1차 구축 (진행 중)
- ✅ content/site.py 용인 구조로 변경 (BRAND, BASE_URL, NAV)
- ✅ content/main.py 메인 페이지 용인 구조로 리라이팅
- ✅ build.py 푸터 용인으로 업데이트
- 🔄 content/areas.py - 30개 지역 페이지 (에이전트 생성 중)
- ⏳ content/stations.py - 24개 역세권 페이지
- ⏳ content/areas_and_stations.py - 16개 생활권 페이지

### 2차 확장 예정
- ⏳ 내부 링크 롱테일 키워드 강화
- ⏳ E-E-A-T 신호 강화 (저자 정보, 신뢰 신호)
- ⏳ Google News 대비 (저자 바이라인, 연락처 명확화)

## 배포 전 할 일

1. `content/areas.py`, `stations.py`, `areas_and_stations.py` 완성
2. `content/site.py`의 `BASE_URL`을 실제 도메인으로 변경
3. `python3 build.py` 재실행 및 검증
4. Google Search Console에 `sitemap.xml` 제출
5. 구조화된 데이터 (Schema.org) 검증

## 특징

- **럭셔리 다크 팔레트**: 어두운 네이비 배경 + 오렌지 #FF6B35 액센트
- **Pretendard 폰트**: 한국식 산세리프 폰트 (최상의 가독성)
- **글래스모르피즘**: 반투명 오버레이, 블러 효과
- **반응형 디자인**: 모바일·태블릿·데스크톱 완벽 지원
- **접근성**: WAI-ARIA, 시맨틱 HTML, 키보드 네비게이션
- **성능**: 정적 HTML (CDN 친화적, 로딩 속도 빠름)
- **푸터 개선**: 오렌지 버튼 2개 (웹사이트 제작문의, 제휴문의) + 텔레그램 링크

## 컨텍스트 - 용인시 구조

**용인시는 광역도시로 생활권이 뚜렷하게 구분됩니다:**

- **처인구**: 용인 원도심 + 에버라인 + 차량 이동 생활권
  - 역북동, 김량장역, 용인중앙시장역, 삼가동, 포곡읍, 양지읍, 남사읍, 이동읍, 백암면, 원삼면 중심

- **기흥구**: 수인분당선·에버라인 환승역세권 중심
  - 기흥역, 신갈역, 구성역, 동백역, 보정역, 신갈동, 구갈동, 동백동, 보정동, 구성동, 마북동 중심

- **수지구**: 신분당선 중심의 신주거 생활권
  - 수지구청역, 죽전역, 성복역, 상현역, 동천역 중심
  - 풍덕천동, 신봉동, 죽전동, 동천동, 상현동, 성복동 중심

**SEO 전략**: 3개 구 허브 → 30개 지역 → 24개역 → 16개 생활권으로 계층화하여 롱테일 키워드와 지역별 검색 의도를 정확히 포착합니다.
